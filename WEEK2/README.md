# Week 2 — Advanced JavaScript & Object-Oriented Patterns

## 📘 Overview

This repository contains JavaScript practice exercises and mini-projects focused on:

- Array operations
- Spread & rest operators
- Shallow vs deep copy
- Timers and asynchronous JavaScript
- Modular programming
- Object-oriented concepts

# ▶️ How to Run

### Run Single File

```bash
node filename.js
```

Example:

```bash
node Shopping_Cart.js
```

### Run Multi-file Applications

```bash
cd E-commerce_cart
node app.js
```

```bash
cd Task_Management
node app.js
```
